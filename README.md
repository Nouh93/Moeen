# مُعين 🇾🇪

منصة متاجر إلكترونية يمنية — "سلة" مبنية لواقع اليمن: الكاش، الواتساب، انقطاع الكهرباء، غياب العناوين، وانقسام العملة.

## ما المنجز حتى الآن (المرحلة 1 — MVP)

- **الواجهة الخلفية** (`apps/api`): NestJS + Prisma + PostgreSQL
  - دخول برقم الجوال اليمني + رمز تحقق OTP (واتساب لاحقاً — في التطوير يظهر الرمز مباشرة)
  - متاجر متعددة المستأجرين (كل تاجر معزول ببياناته)
  - منتجات (أسعار، خصومات، مخزون بخصم آمن داخل معاملة واحدة)
  - طلبات COD بدورة حالات كاملة: جديد ← تجهيز ← مع المندوب ← تسليم/إلغاء/إرجاع
  - **idempotency**: إعادة إرسال الطلب بعد انقطاع الإنترنت لا تكرره (القسم 22.1.2)
  - نموذج العنوان اليمني: محافظة + مديرية + حي/عزلة + وصف حر (القسم 23.2)
  - تتبع عام برمز قصير `MN-XXXXXX` بدون تسجيل دخول
- **الواجهة الأمامية** (`apps/web`): Next.js عربية RTL
  - صفحة تعريفية + واجهة متجر + صفحة منتج + سلة وإتمام طلب في صفحة واحدة
  - حفظ الطلب محلياً وإرساله تلقائياً عند عودة الاتصال (Offline)
  - صفحة تتبع الطلب مع خط زمني
  - لوحة تاجر كاملة من متصفح الجوال: طلبات (مع زر واتساب للعميل)، منتجات، إعدادات
- **بيانات مشتركة** (`packages/shared`): المحافظات الـ 22 ومديريات مدينتَي الإطلاق، حالات الطلب وانتقالاتها، العملات (بما فيها انقسام الريال صنعاء/عدن)

## التشغيل محلياً

المتطلبات: Node 20+، pnpm، PostgreSQL.

```bash
pnpm install
cp apps/api/.env.example apps/api/.env   # عدّل DATABASE_URL إن لزم
pnpm db:migrate                           # إنشاء الجداول
pnpm db:seed                              # المحافظات + متجر تجريبي (alafia)
pnpm dev:api                              # http://localhost:4000
pnpm dev:web                              # http://localhost:3000
```

- متجر تجريبي: `http://localhost:3000/s/alafia`
- لوحة التاجر: `http://localhost:3000/dashboard` — جوال التاجر التجريبي `771234567` (رمز OTP يظهر على الشاشة في وضع التطوير)
