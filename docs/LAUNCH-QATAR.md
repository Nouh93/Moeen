# خطة إطلاق مُعين من قطر 🇶🇦 → 🇾🇪

الإطلاق من قطر منطقي لثلاثة أسباب: **قرب جغرافي ممتاز لليمن** (زمن استجابة الدوحة→صنعاء ~50-70ms، مكافئ للإمارات)، **بنية سحابية عالمية داخل قطر** (Google Cloud Doha وMicrosoft Azure Qatar Central)، و**بيئة تأسيس شركات صديقة للتقنية** (QFC/QSTP بملكية أجنبية 100%) تسهّل توقيع عقود MEPS وWhatsApp BSP باسم كيان قانوني.

> هذا الدليل يكمّل `DEPLOYMENT.md` (الخطوات التقنية التفصيلية هناك) — هنا القرارات والخطوات الخاصة بقطر بالترتيب.

---

## المرحلة 1 — البنية التحتية (أنت تنفذها — يوم واحد)

### الخيار الموصى به: Google Cloud منطقة الدوحة `me-central2`
| البند | القيمة |
|---|---|
| الجهاز | `e2-standard-2` (2 vCPU / 8GB) — يكفي للـ Pilot وزيادة |
| التكلفة | ~85$ شهرياً (وحساب جديد يأخذ رصيد 300$ مجاني ≈ 3 أشهر) |
| النظام | Ubuntu 24.04 LTS، قرص 50GB |
| الجدار الناري | افتح 80 و443 فقط (بعد إعداد Caddy) |

البديل: **Azure Qatar Central** (`B2ms` بسعر مقارب). البديل الاقتصادي إن لم تُرد سحابة قطرية: أي VPS خليجي — الفرق العملي على مستخدم يمني صغير لأن الثابت يُخدم من Cloudflare.

### الدومين
- احجز عبر Cloudflare Registrar أو Namecheap (يقبلان بطاقات قطرية): `.com` أو `.store`
- أضف الموقع إلى **Cloudflare** (الخطة المجانية تكفي) — هذا يعطي CDN وحماية DDoS من أقرب نقطة للمستخدم اليمني (متطلب القسم 22.3.1)

### ✅ ما تعود به إليّ بعد هذه المرحلة
1. عنوان IP السيرفر
2. اسم الدومين
3. رقم جوالك الذي سيكون **حساب مدير المنصة**

## المرحلة 2 — النشر (ننفذها معاً — ساعتان)

على السيرفر، اتبع `DEPLOYMENT.md` حرفياً، مع فرق وحيد لقطر:

```bash
# رقم مدير المنصة يُحدد بمتغير بيئة عند البذر (بدون تعديل كود):
ADMIN_PHONE=+9677XXXXXXXX docker compose -f docker-compose.prod.yml \
  exec -e ADMIN_PHONE api npx ts-node -T prisma/seed.ts
```

أرسل لي مخرجات أي أمر يتعثر وأصححه فوراً.

## المرحلة 3 — الخدمات الخارجية (أنت توقعها — أسبوع بالتوازي)

| الخدمة | من أين | التكلفة التقريبية | ثم ماذا |
|---|---|---|---|
| **WhatsApp Business API** | مزوّد BSP مثل 360dialog أو Twilio — التسجيل بكيانك القطري أسهل بكثير | ~50$/شهر + رسوم رسائل | تعطيني API Key وأوصله (موضع TODO واحد في الكود) |
| **رقم أعمال واتساب** | رقم مخصص (يُفضَّل يمني أو قطري) غير مستخدم في واتساب عادي | — | يُوثَّق عبر الـ BSP |
| **شركة توصيل يمنية** | اتفاق مبدئي مع شركة واحدة في صنعاء أو عدن | عمولة لكل شحنة | نضيف أسعارها في المنصة |
| **eSadad / MEPS** (لاحقاً) | مراسلات رسمية — كيان قطري يقوّي موقفك التفاوضي | حسب الاتفاق | أربط الـ webhooks الجاهزة |

## المرحلة 4 — الكيان القانوني (بالتوازي، غير حاجز للـ Pilot)

- **QSTP** (واحة قطر للعلوم والتكنولوجيا) أو **QFC**: ملكية أجنبية 100%، مناسبة لشركة تقنية، وتمنحك حساباً بنكياً قporate توقّع به العقود
- ملاحظة الوثيقة (القسم 24.7) تبقى: نشاط الدفع داخل اليمن يحتاج لاحقاً تنسيقاً مع الجهات اليمنية — الكيان القطري يغطي الطرف الدولي (BSP، السحابة، MEPS)

## قائمة انطلاق الـ Pilot (الأسبوعان الأولان)

- [ ] سيرفر الدوحة + الدومين + النشر ✅ (المراحل 1-2)
- [ ] واتساب BSP موصول ورسالة حقيقية وصلت
- [ ] 10 تجار أوائل (معارف/مجموعات) يفتحون متاجرهم — الباقة المجانية
- [ ] أول 20 طلب COD حقيقي مكتمل
- [ ] مراجعة أسبوعية: أين تعثر التجار؟ (تغذية مباشرة للتطوير)

**الهدف قبل التوسع**: 50 تاجراً نشطاً و500 طلب مكتمل — عندها نبني تطبيق المندوب والأكاديمية على احتياجات حقيقية لا افتراضات.
