# مُعين 🇾🇪

منصة متاجر إلكترونية يمنية — "سلة" مبنية لواقع اليمن: الكاش، الواتساب، انقطاع الكهرباء، غياب العناوين، وانقسام العملة.

## ما المنجز حتى الآن

### الواجهة الخلفية (`apps/api`) — NestJS + Prisma + PostgreSQL + Redis
- دخول برقم الجوال اليمني + رمز تحقق OTP، مع حماية من الإغراق وحدود معدل طلبات عامة
- متاجر متعددة المستأجرين (كل تاجر معزول ببياناته)
- منتجات: أسعار وخصومات، **تصنيفات**، **رفع صور** (multer + خدمة ملفات ثابتة)، مخزون بخصم آمن داخل معاملة
- طلبات COD بدورة حالات كاملة + **idempotency** (إعادة الإرسال بعد الانقطاع لا تكرر الطلب)
- **إشعارات واتساب عبر طابور BullMQ** بإعادة محاولة تصاعدية (1د/5د/30د) وسجل تدقيق كامل — قوالب بالأسلوب اليمني (القسم 26.2): تأكيد الطلب، تحديث الحالة، طلب جديد للتاجر، تنبيه نقص مخزون
- **كوبونات**: نسبة/مبلغ، حد أدنى، عدد استخدامات، انتهاء — مع تحقق عام للسلة
- **أسعار شحن لكل محافظة** + توصيل مجاني فوق مبلغ + مدة توصيل معلنة
- **إحصائيات للتاجر**: مبيعات اليوم/الأسبوع/الشهر، الطلبات بالحالة، الأكثر مبيعاً
- بحث الطلبات (رمز/اسم/جوال) مع ترقيم صفحات
- نموذج العنوان اليمني + تتبع عام برمز `MN-XXXXXX` بدون تسجيل

### الواجهة الأمامية (`apps/web`) — Next.js عربية RTL (أول تحميل ≤ 115KB)
- واجهة متجر: تصنيفات + **بحث عربي متسامح** (همزات/تاء مربوطة) + شعار المتجر + SEO (OpenGraph)
- سلة وإتمام طلب بصفحة واحدة: **كوبون** + **شحن حسب المحافظة** + توصيل مجاني + **تذكّر بيانات العميل** + إرسال تلقائي عند عودة الاتصال
- **PWA**: manifest + Service Worker (الصور والأصول تعمل بدون إنترنت بعد أول زيارة)
- لوحة تاجر بـ 5 تبويبات: **نظرة عامة** (إحصائيات)، **الطلبات** (فلاتر + بحث + ترقيم + **بوليصة شحن للطباعة**)، **المنتجات** (تعديل كامل + رفع صور من الجهاز + تصنيفات)، **الكوبونات**، **الإعدادات** (شعار + أسعار شحن المحافظات)
- صفحة تتبع الطلب بخط زمني

### الباقات ومحرك تحصيل الاشتراك (القسم 24) — «آلي بالأصل، يدوي للاستثناء»
- **3 باقات** (بداية مجانية / نمو / احتراف) بحدود مفروضة فعلياً (20 منتجاً للمجانية، الكوبونات للمدفوعة) — والدفع السنوي بشهرين مجانيين
- **فواتير بمرجع فريد عالمياً** `MOEEN-<كود التاجر>-<سنةشهر>`
- **محرك مطابقة آلية**: كل أحداث الدفع (مُجمِّع، MEPS، حوالة بنكية، يدوي) تدخل طابور ابتلاع BullMQ واحد وتُطابق بالمرجع — **idempotent** (تكرار الإشعار لا يفعّل مرتين)، الغامض يذهب لطابور استثناءات
- **محفظة تاجر مسبقة** بدفتر أستاذ append-only — لا رصيد سالب إطلاقاً (الحد = 0)، وفائض أي دفعة يُقيَّد للمحفظة، والتجديد يُخصم منها تلقائياً (تحصيل صفري التدخل)
- **دورة الإنذار الكاملة**: تذكير يوم 7 و10 → تعليق يوم 15 (المتجر يُخفى واللوحة تعمل) → إنذار نهائي يوم 30 → إغلاق يوم 37 — مع حماية التاجر الجديد (أول شهرين لا تعليق)، والسداد يعيد المتجر فوراً وآلياً
- **Webhooks** للمُجمِّع والبنك وMEPS بسر مشترك + جدولة يومية (BullMQ repeatable)
- تبويب 💳 الاشتراك في اللوحة: باقات، محفظة، فواتير بتعليمات السداد، دفتر الحركات، وشريط تعليق أحمر بزر «ادفع الآن»

### الهوية البصرية
خط Tajawal العربي، نظام بطاقات موحّد بظلال ناعمة، رؤوس متدرجة بهوية مُعين، صفحة رئيسية تسويقية كاملة (بطل، مزايا، خطوات، باقات)

### بيانات مشتركة (`packages/shared`)
المحافظات الـ 22 ومديريات مدينتَي الإطلاق، حالات الطلب وانتقالاتها المسموحة، العملات (بما فيها انقسام الريال صنعاء/عدن)، تعريفات الباقات وأسعارها، جدول دورة الإنذار

## التشغيل محلياً

المتطلبات: Node 20+، pnpm، PostgreSQL.

```bash
pnpm install
cp apps/api/.env.example apps/api/.env   # عدّل DATABASE_URL إن لزم
pnpm db:migrate                           # إنشاء الجداول
pnpm db:seed                              # المحافظات + متجر تجريبي (alafia)
pnpm dev:api                              # http://localhost:4000
pnpm dev:web                              # http://localhost:3000
```

- متجر تجريبي: `http://localhost:3000/s/alafia`
- لوحة التاجر: `http://localhost:3000/dashboard` — جوال التاجر التجريبي `771234567` (رمز OTP يظهر على الشاشة في وضع التطوير)
